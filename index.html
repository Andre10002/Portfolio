Secure Azure web app deployment

TU Dublin, Security Administration

A web app environment on Azure where the database can’t be reached from the internet, and each user role only gets the access it needs.

  • Split the VM, SQL Database and Blob Storage into separate subnets, with Network Security Groups and private endpoints.
  • Built a custom RBAC matrix for three roles and tested access as each one.
  • Added SSH key-only login, PAM lockout, TLS 1.2, Transparent Data Encryption, fail2ban and AIDE.
  • Automated daily security checks, backups and log retention with Bash and cron.
  • Azure
  • Linux
  • Bash
  • RBAC
  • NSGs

SOC log analysis and threat detection tool

PowerShell, personal project

A modular PowerShell tool that reads raw logs and writes one investigation report, the way an analyst would triage an alert queue.
